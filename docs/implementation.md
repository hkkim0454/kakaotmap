# 바로길 구현 계획

승인된 흐름: 주소·장소 검색 → 목적지 확인 및 지도 → TMAP 또는 카카오내비 버튼을 눌러 앱 실행.

사용자가 제작 후 직접 앱 실행을 확인하기로 했으므로 현재 빈 작업 폴더에서 구현한다. 별도 배포나 계정 생성은 하지 않는다.

## 구조
- public/index.html, styles.css: 모바일 중심 화면, 참고 이미지의 둥근 흰색 내비 카드.
- public/navigation.js: 좌표 검증, 운영체제 구분, TMAP 실행 링크, 카카오내비 인자.
- public/app.js: 카카오 지도 SDK의 키워드/주소 검색, 목적지 선택, SDK 준비 후 동기 앱 호출, 설정 화면.
- server.mjs: 외부 의존성 없는 Node 정적 서버. public만 허용하고 .env 등은 제공하지 않는다.
- tests/: 잘못된 좌표, 한글·특수문자 목적지, Android/iOS 링크, 검색 결과 병합, 서버 경로 노출 검사.

## 작업
1. 내비 링크와 검색 데이터 정규화 테스트를 작성하고 실패 확인 후 구현한다.
2. 검색·지도·버튼 UI 및 공개 JavaScript 키 설정을 구현한다. REST/관리자 키는 요구하지 않는다.
3. Node 서버 및 실행 안내를 작성하고 전체 테스트 및 브라우저 화면을 검증한다.

## 완료 조건 및 남는 확인
- 검색 결과의 이름과 WGS84 경도/위도를 목적지로 사용한다.
- 사용자 클릭 핸들러 안에서 대기 없이 앱 호출. 앱 열기 성공으로 단정하지 않는다.
- 키 미설정 시 예시 목적지임을 표시하고 실제 검색은 사용 불가 이유를 안내한다.
- 지도와 내비 SDK 오류는 개별 처리한다.
- 설치 안내는 사용자가 선택하며 임의 시간 후 스토어로 강제 이동시키지 않는다.
- Android/iOS 실기기 및 카카오톡 인앱 브라우저의 실제 앱 전환은 사용자 검증으로 남긴다.
- TMAP URL scheme은 실제 기기의 호환성 확인이 필요하다.

## 검증 기록
- 구현 및 Node 테스트 7개 통과: 인코딩, 좌표, 데이터 병합, OS 판별, 비공개 파일 차단.
- JavaScript 구문 검사 통과.
- 로컬 서버를 3000번 포트에서 실행.
- 브라우저 UI 확인은 자동화 도구에 연결된 브라우저가 없어 수행하지 못함.
- 실제 키를 제공받지 않아 인증된 검색/지도 및 카카오내비의 실제 실행은 미검증.
